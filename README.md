# Portfolio — earlier Django implementation

This repository contains an earlier Django portfolio. The proposed canonical recruiter portfolio is maintained at https://github.com/DataByRajesh/DataByRajesh.github.io and intended for https://databyrajesh.github.io/ once published.

The portfolio templates now present the same factual recruiter profile, replacing template jobs, testimonials and unrelated sample projects.

See EVIDENCE_CHECKLIST.md for the information required to complete the case studies and CV links.

Repository hygiene: .gitignore prevents new virtual environments, databases, caches and local IDE files from being tracked. Existing tracked development artefacts require a separate reviewed cleanup; ignoring them does not remove them from history.

The Django application has not been run or deployment-tested in this change. The replacement HTML passed structural and anchor checks; browser visual verification remains pending.
